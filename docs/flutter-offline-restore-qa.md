# اختبار الاستعادة المحلية وتحديث أندرويد

## نطاق المطابقة

يُقرأ ملف المستخدم محليًا. تعرض شاشة النسخ بصمة SHA-256 للملف المختار، ويعرض تقرير SQLite القديم بصمة قاعدة البيانات بعد فك الضغط أيضًا. يبيّن تقرير الفحص الجداول المأهولة والأعمدة وأنواعها وحقول التحويل المعروفة والحقول غير المطابقة. يسرد معرّف كل حركة ذات عملة مفقودة. لا يحتوي التقرير على ملف القاعدة.

| المصدر | المقابل في الهاتف | شرط القبول |
| --- | --- | --- |
| workspaces | اسم المنشأة وتفضيلات الرسائل | منشأة واحدة محددة |
| currencies وboxes | عملات، أسعار، مجموعات | أسماء عملات مدعومة وأسعار موجبة وتصنيف معروف |
| customers | حساب وعضوية ورصيد افتتاحي | مرجع مجموعة صالح واتجاه ومبلغ افتتاحي صريحان |
| cboxes | حساب نقدي مرتبط بسجل الصندوق | ارتباط حساب صريح بنفس العملة. تشابه الاسم أو الرقم لا يكفي |
| stores وproducts | مستودع وصنف ووحدة ورصيد | كمية ومخزن صريحان لكل صنف في المخطط المدعوم |
| input_move وbill_details | سند أو فاتورة أو مردود تاريخي وبنوده | تاريخ حقيقي واتجاه مالي واحد وسعر صرف معلوم، وتطابق المبلغ والبنود للمستندات الصنفية |
| store_trans وtrans_details | تحويلات مخزنية تاريخية | مخزنان مختلفان وموجودان وبنود مرتبطة بالصنف ووحدته الأساسية. لا يُعاد تطبيق التحويل على الرصيد الحالي |

الاستعادة محدودة بالمخطط الذي يحمل هذه الأدلة. يحظر التحويل عند وجود جدول مأهول غير مدعوم، أو حقل غير مطابق في جدول مأهول، أو خصم أو تسوية نقدية يحتاجان إلى تفسير. ملفات SmartPro التي لا تتضمن مخزونًا مثبتًا لكل صنف أو رابطًا بين الصندوق والحساب تحتاج إلى أدلة إضافية. توصّل مستورد الخادم في بعض هذه الحالات إلى مخزن اعتمادًا على بنود المستندات، ووسم الكمية بأنها غير متحققة. لم تُنقل هذه القاعدة إلى مسار الاستعادة.

## نتائج بيانات الاختبار

| القيمة | مصدر SQLite في الاختبار | بعد تحويله وإغلاق قاعدة الهاتف الاختبارية وإعادة فتحها |
| --- | --- | --- |
| حساب 11، افتتاحي | 12.25 دولار دائن | 12.25 دولار دائن |
| فاتورة 31 | 1.5 وحدة × 7 دولارات | 10.50 دولارات |
| صافي الحساب | 1.75 دولار دائن | 1.75 دولار دائن |
| الصنف 22 في مخزن 4 | 17.25 وحدة | 17.25 وحدة |
| سبع حركات ذات عملتين مجهولتين | حركتان للعملة 2 وخمس للعملة 3 | رُفضت الاستعادة وسُجّلت المعرّفات |

هذه أرقام بيانات الاختبار. أعداد الأرصدة وبنود فاتورة هلال الفعلية غير متحققة. يكتب اختبار الاستعادة في مسار مؤقت ثم يعيد فتحه ويفحص السجلات والمجاميع. لا تُستعمل قاعدة الموقع أو قاعدة هاتف المستخدم في هذه الاختبارات.

## إعادة تشغيل الفحوص

من flutter_app على Flutter 3.29.0:

```sh
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test
```

تغطي legacy_conversion_test وweb_backup_restore_test المخطط القديم، JSON الموحد، ملفًا تالفًا، العملات والمراجع، الرفض الذري، والبقاء بعد إعادة الفتح. يختبر dev_update_resume_test استكمال 206، وإعادة تنزيل رد 200، ورفض الجزء الخاطئ والبصمة الخاطئة. يقارن backup_arabic_golden_test صور الوضعين الفاتح والداكن على عرض 320 نقطة مع تكبير النص.

تحتاج نتيجة الرسم إلى فحص على جهاز المشكلة. سجّل طراز الهاتف وإصدار أندرويد والمحرك والنسخة، وقارن البطاقة نفسها على Skia وImpeller في الوضعين. للتحقق من تحديث الجهاز، استخدم هاتف اختبار ببيانات تجريبية معروفة. احفظ تقرير الأرصدة والكميات، وثبّت التحديث من التطبيق بموافقة النظام، ثم افتح التطبيق في وضع الطيران وقارن التقريرين. عند فشل أي مقارنة يبقى الإصدار التجريبي خارج قناة النشر.
