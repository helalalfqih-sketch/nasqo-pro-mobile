# NASQO Flutter 1.0.17+18 — Source QA

حزمة مصدر محلية تجريبية، لا إصدار إنتاج ولا نسخة من بيانات العمل.
Flutter 3.29.3 / Dart 3.7.2؛ Android QA package: com.indexesstore.nasqo_qa.
المخطط الحالي SQLite v9. مجلد docs يحوي خططاً تاريخية، وليس إثباتاً لتنفيذ جميع مراحلها.

## تشغيل نسخة اختبار مستقلة
- ثبّت Flutter والأدوات الرسمية وJDK 17 وAndroid SDK الموافق لإعدادات البناء.
- شغّل الأوامر من مجلد flutter_app:

```sh
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --debug --no-pub
```

يعيد Flutter توليد local.properties وGeneratedPluginRegistrant.java محلياً؛ لم تُضمَّن مسارات جهاز البناء أو ملفات التسجيل المولدة. بعض اختبارات FFI تحتاج SQLite على المضيف، واختبار بصمة النسخ يستخدم sha256sum على Linux. لا تتجاوز إخفاقات الاختبار أو تضف بيانات حقيقية.

## حدود الحزمة
- لا APK أو keystores أو شهادات توقيع أو أسرار أو قواعد بيانات أو نسخ احتياطية أو ملفات عملاء.
- المبالغ والأسماء داخل بيانات الاختبارات والبذور أمثلة تركيبية من المصدر.
- المسودات غير المرحلة ليست عمليات مالية منفذة. لا تستورد بيانات عمل حقيقية بغرض التجربة.
- طباعة PDF تفتح نافذة نظام Android بطلب صريح؛ فتحها لا يثبت نجاح الطباعة. اختيار صفحات جزئية غير مدعوم ويُرفض.
- نتائج الاختبارات أو بناء APK يجب إعادة التحقق منها في بيئتك؛ هذه الحزمة لا تدّعي اعتماد جهاز أو طابعة أو صلاحية إنتاج.
- أُرفقت خطوط Noto وترخيصها وشعار التطبيق وGradle Wrapper اللازم للبناء. لم تُضمَّن ذاكرات البناء أو SDK أو الاعتماديات المحملة.

SOURCE-MANIFEST.json يضم الحجم وبصمة SHA-256 لكل ملف مصدر/أصل مُرفق. البصمات فحص سلامة وليست توقيع أصالة.
