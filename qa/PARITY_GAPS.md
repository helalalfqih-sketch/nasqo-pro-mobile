# الدفعة 01 — فروقات شاشة مجموعات الحسابات والأرصدة

| العنصر | نتيجة الفحص | ما يتبقى للاعتماد |
|---|---|---|
| الأرصدة المحلية والمستعادة | في اختبارات Flutter يظهر الدائن `1,250.5-` والمدين `80`. لون الدائن في الفاتح `#9f1239` والداكن `#fb7185`، ولون المدين `#0b5ca8` و`#60a5fa`، كما في CSS المحسوب للمرجع. | ملاحظة وضوح الأرقام على هاتف المستخدم. |
| كل العملات | المرجع يعرض في عينة الاختبار مجموعًا اسميًا مقداره `1,225.5-` عند جمع رصيد سالب بالريال مع 25 دولارًا. يعرض Flutter سطرًا لكل عملة مع اسمها ويستعمل حساب العملة الموجودة فعليًا. نجحت مقارنة صفوف SQLite قبل اختيار المرشح وبعده. | مراجعة استثناء العرض المحاسبي وقبوله من المستخدم. |
| الجدول | عند عرض 427 وDPR 1، ارتفاع React هو 151 بكسل وFlutter هو 144. تختلف عروض عمود العملة والاسم، ومحاذاة رأس الجدول، ولون اسم المجموعة، وسهم وحدود محدد العملة. | ضبط هندسة الجدول ومقارنة لقطة كاملة على Android وتكبير خط الجهاز. |
| التصفح | اختبارات قائمة المجموعات ومسارات Flutter وسلامة أوامر الجسر موجودة. | قياس العودة إلى الموضع نفسه بعد فتح كشف الحساب، خصوصًا في الوضع المحلي، وفحص TalkBack ولوحة المفاتيح. |
| Hybrid | حُزّم الخط وواجهة React في تجربة مستقلة. نجحت قراءة SQLite بعد فتحين، وعزل أوامر العرض، واختبار Chromium دون شبكة. | قياس بدء العرض، وزمن الإطارات والذاكرة على الجهاز نفسه، والتشغيل البارد للمختبر بوضع الطيران. القرار المعماري معلّق. |
| الشاشة الرئيسية | تدخل حالات السحب والحفظ والمفضلة في المصفوفة منفصلة عن شاشة الأرصدة. | السحب والحفظ مفقودان، والمفضلة تحتاج مراجعة مستقلة. |
