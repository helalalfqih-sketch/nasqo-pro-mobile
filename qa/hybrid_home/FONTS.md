# Offline fonts for the hybrid home

The original web entry point requests IBM Plex Sans Arabic at weights 400, 500, 600 and 700. The Android asset directory contains the same four static weights. Each file was checked against its Git blob in the upstream Google Fonts tree. The bundled SIL Open Font License is `flutter_app/android/app/src/main/assets/hybrid_home/fonts/OFL.txt`.

[Upstream files at the pinned revision](https://github.com/google/fonts/tree/702964cf46bd1bf33d0745d24bbaac33edf8b8af/ofl/ibmplexsansarabic)
